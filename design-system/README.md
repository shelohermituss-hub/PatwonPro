# design-system/

Mete la asset ekspò design system pwojè a (Figma export, tokens JSON,
ikòn SVG, elt.) — dekonprese ZIP la dirèkteman nan dosye sa a.

Jiskaske yon ekspò ajoute, gid design pwojè a se **`docs/DESIGN_SYSTEM.md`**
(palèt koulè, tipografi, konpozan kle).

## Lè yon ZIP ajoute

1. Dekonprese l isit la (`design-system/`).
2. Pote tokens koulè/tipografi yo nan `src/app/globals.css` (blòk `@theme`).
3. Pote ikòn/asset SVG yo nan `src/components/icons/`.
4. Mete `docs/DESIGN_SYSTEM.md` ajou si vrè valè yo diferan de pwen depa a.
